Project III • Recursive Self-Improvement & Continuous Learning

Zero-Hallucination Causal Self-Training

Unlike pure conversational models that degrade from ungrounded self-play, AutogenOS uses the physical operating system (exit codes, DOM states, accessibility trees, file checksums) as an uncheatable ground truth reward model.

Phase 01 // Causal Grounding

Objective OS Reward

Progress is only recognized when environmental evidence confirms state change (exit code 0, SHA-256 match, accessibility focus). Hallucinations are physically blocked by the Verifier.

Phase 02 // DPO / SFT Synthesis

Preference Generation

Failed action proposals and subsequent verified repairs are automatically paired into (Rejected, Chosen) preference samples ready for offline LoRA fine-tuning without human labels.

Phase 03 // Reflexion Heuristics

Episodic Memory Bank

Environmental rejections are distilled into negative rules (e.g. "Avoid legacy coordinates on Ribbon"). Injected into Planner pre-flight contexts to permanently eliminate repeat errors.

Phase 04 // Tool Induction

Organic Skill Synthesis

Frequent multi-step execution sequences are autonomously mined and compiled into new reusable MCP tools and Python skills, expanding swarm capabilities automatically.

API & Developer SDK

One Library. Any Interface.

Integrate the AutogenOS Python library, command line binary, or high-performance FastAPI REST and WebSocket endpoints into your autonomous stack. 

import asyncio
import autogenos as agy

async def main():
    # 1. Initialize Swarm Orchestrator with Planner-Actor-Verifier lifecycle
    orchestrator = agy.SwarmOrchestrator()

    # 2. Gate tools dynamically via Tool Attention (eliminates MCP token tax)
    engine = agy.ToolAttentionEngine()
    active_tools = engine.gate_tools("Process financial invoice and compute file hash", top_k=2)

    # 3. Execute closed-loop long-horizon task with causal verification
    controller = agy.SwarmGraphController()
    state = await controller.run_full_lifecycle(
        "Audit spreadsheet records and verify checksum with zero side effects"
    )

    print(f"Task Phase:      {state.phase.value}")
    print(f"Verified Proofs: {len(state.accumulated_evidence)}")
    print(f"Tokens Pruned:   {state.token_usage_pruned} tokens via CarryOn")

if __name__ == "__main__":
    asyncio.run(main())
